## low-level (main)

### main_0.5 — ขาเปล่าบินต่ำลง 1 บล็อก
- แยกความสูงเดินทางเป็น 2 แบบ: ขาที่ถือบล็อก (carry) กับขาตัวเปล่า (empty)
  - ถือบล็อก: 2.5x / 3.5x / 4.5x ของความสูงบล็อก (เท่าเดิม — เผื่อใต้บล็อกที่ถือ 0.5 บล็อก)
  - ตัวเปล่า: 1.5x บนโต๊ะ และ (ความสูง Tower + 0.5) เมื่อออกจาก Tower
- สูตรรวมอยู่ใน `safe_z_for(..., carrying=True/False)` = (สิ่งกีดขวางสูงสุด + 1.5 หรือ 0.5) x ความสูงบล็อก
- ถ้าหน่วงหัวดูด = 0 ms จะไม่ส่งคำสั่ง WAIT เข้าคิวเลย (คิวเหลือ 56 คำสั่งต่อรอบ)
- ⚠️ ขาเปล่าเหนือ Tower เหลือระยะห่างแค่ 0.5 บล็อก (12.5 mm) และการเคลื่อนที่แนวราบเป็นแบบ MOVJ
  ซึ่ง Z อาจแกว่งลงระหว่างทาง — ถ้าเฉี่ยว ให้เพิ่มเลข 0.5 ใน `safe_z_for()`

### main_0.41 — ทดลอง JUMP (ช้ากว่า เลิกใช้)
- ใช้คำสั่ง JUMP_XYZ (ยก-เคลื่อน-ลง ในคำสั่งเดียว) แทนการสั่งทีละท่อน
- ตั้ง `jumpHeight = safe_z - z ปัจจุบัน` และ `zLimit = safe_z` ให้ความสูงเดินทางเท่าเดิม
- เพิ่มค่า `jump_speed` / `jump_accel` เพราะช่วงขึ้น-ลงของ JUMP วิ่งด้วยความเร็วแนวเส้นตรง (ช้ากว่า MOVJ)
- ผลจริง: 42.78 วินาที (ค่าเริ่มต้น) และ 26.43 วินาที (ความเร็ว 500) เทียบกับ main_0.4 ที่ 24.17 วินาที
- สรุป: JUMP ช้ากว่า จึงไม่ใช้ต่อ และลบไฟล์ทิ้งแล้ว

### main_0.4 — เวอร์ชัน lightweight + ส่งทั้งชุดเข้าคิว
- ลดเหลือ 5 เมนู: `[1]Run [2]Teach&Save [3]SetGround [4]Save&Exit [Enter]Exit` (221 บรรทัด จาก 622)
- ตัดเมนูย่อย Settings, Adjust Speed, View Settings, สรุปตาราง 3x3 และ preview ต่างๆ ออก
- `[4] Save&Exit` เป็นทางเดียวที่เขียน `settings.json` แล้วปิดโปรแกรม / `[Enter]` ออกโดยไม่บันทึก
- ส่งคำสั่งทั้งชุดของแต่ละบล็อกเข้าคิวของหุ่นยนต์ทีเดียว แล้วรอแค่บล็อกก่อนหน้า
  (คิวไม่เกิน 2 บล็อก ~22 คำสั่ง < 32) — ไม่มีช่วงรอฝั่ง Python ระหว่างแต่ละท่อน
- หน่วงหัวดูดใช้คำสั่ง WAIT (ID 110) ที่รันบนหุ่นยนต์ แทน `time.sleep()` — ตั้งที่
  `SUCK_DELAY_MS` / `RELEASE_DELAY_MS` (ปัจจุบันตั้ง 0 ms ทั้งคู่ ทดสอบแล้วบล็อกไม่หลุด)
- ตัดการยกขึ้นหลังวางบล็อก — การยกครั้งถัดไปยกตรงไปที่ Safe Z ของบล็อกถัดไปครั้งเดียว
- ตัด `time.sleep(0.1)` หลังทุกการเคลื่อนที่ (ไม่มีผล เพราะรอคำสั่งเสร็จอยู่แล้ว) ~5.8 วินาที/รอบ
- ถาม `get_pose()` ครั้งเดียวตอนเริ่มรัน (เดิมถามทุกบล็อก) โดยจำตำแหน่งล่าสุดไว้เอง
- Ctrl+C / ออกจากโปรแกรม: สั่งหยุดฉุกเฉิน (ID 242) + ล้างคิว (ID 245) + ปิดหัวดูด
  เดิม Ctrl+C หยุดแค่ Python ส่วนหุ่นยนต์ยังวิ่งคำสั่งที่ค้างในคิวต่อ
- แสดงเวลาที่ใช้ต่อรอบเป็นวินาที ท้ายข้อความ "สร้าง Tower เสร็จ"

### main_0.3 — Smart Ground + เมนูตั้งค่า
- คำนวณความสูงทุกจุดจากระนาบพื้น (Ground Z) + ความสูงบล็อก แทนการใช้ค่า Z ดิบจากการสอน
- Dynamic Safe Z: 2.5x / 3.5x / 4.5x ของความสูงบล็อก ตามความสูง Tower ปัจจุบัน
- เมนูตั้งค่า: Teach, Smart Ground Calibration, Adjust Speed & Params, View Settings, Save
- มี Grip Offset (ระยะกดหัวดูด) และแสดงตารางพิกัดทั้งหมด
- แก้ระหว่างพัฒนา: เดิมเมนู Adjust Parameters บันทึกไฟล์ทันทีที่เปลี่ยนค่า
  เปลี่ยนเป็นให้ `[5] Save & Exit` เป็นทางเดียวที่บันทึก แล้วกลับเมนูหลัก
